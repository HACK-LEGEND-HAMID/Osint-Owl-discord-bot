# Privacy Policy - OSINT-Owl Bot

**Last Updated:** []

## 1. Information We Collect
OSINT-Owl collects minimal data:
- Discord User IDs (for level system)
- Command usage statistics
- Server IDs where bot is added

## 2. What We DON'T Collect
- Personal messages (we don't read DMs)
- Passwords or credentials
- Email addresses
- IP addresses
- Any personal identifying information

## 3. How We Use Data
- Improve bot functionality
- Track popular commands
- Level and XP system
- Bug fixes and updates

## 4. Data Storage
- Data is stored temporarily in memory
- No permanent database of user messages
- Statistics are anonymized

## 5. Data Sharing
- We DO NOT sell your data
- We DO NOT share data with third parties
- Data stays within the bot system only

## 6. Message Content
- Bot only processes messages when mentioned or commanded
- Messages are processed for AI responses only
- No message history is stored permanently

## 7. AI Service
- AI responses use Google Gemini API
- Questions sent to Gemini are not stored by us
- Refer to Google's privacy policy for API usage

## 8. Your Rights
- You can request data deletion
- You can opt out of level system
- Remove bot to stop all data collection

## 9. Children's Privacy
This bot is not intended for users under 13 years of age.
