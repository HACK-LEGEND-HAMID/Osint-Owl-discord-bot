## 🚀 Deployment Guide

### 1️⃣ Create a Server

Create a free server from the WispByte panel.

### 2️⃣ Upload Your Bot

Upload your files through the File Manager or Git repository.

### 3️⃣ Configure Environment Variables

```env
BOT_TOKEN=YOUR_DISCORD_TOKEN
```

### 5️⃣ Start The Bot

Press the **Start** button from the dashboard.
